# Ruby Koans Solutions

My completed solutions for the [Ruby Koans](http://rubykoans.com/) exercises.

## Overview

The Ruby Koans walk along the path to enlightenment in order to learn Ruby. The goal is to learn the Ruby language, syntax, structure, and some common functions and libraries.

## Running the Koans

To verify all solutions, run:

```bash
rake
```

or:

```bash
ruby path_to_enlightenment.rb
```

## Structure

The koans cover:
- Asserts, Truth & Falsehood
- Strings, Symbols, Regular Expressions
- Arrays, Array Assignment, Hashes, Objects, Nil
- Methods, Keyword Arguments, Constants
- Control Statements, Exceptions
- Blocks, Iteration, Sandwich Code
- Classes, Open Classes, Inheritance, Modules, Scope
- Message Passing, Proxy Object Pattern
- Scoring Project & Greed Game (Extra Credit)
